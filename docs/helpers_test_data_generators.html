Test Data Generators¶

Test data generators for dynamic test values.

tests.helpers.test_data_generators.pick_random_movie_id() → int[source]¶

Return a random movie ID from the cached movie_ids.txt list.

The file is read once via _load_movie_ids(); each call only performs an in-memory random choice.

Returns:

Random movie ID

Raises:

  • FileNotFoundError – If movie_ids.txt doesn’t exist

  • ValueError – If file is empty or contains invalid data
